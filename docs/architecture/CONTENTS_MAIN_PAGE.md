# 메인 페이지 구조
1. 비주얼 바형 이큐 박스 메인 대표 배너로 표시
    - 어떤곡을 쓸지, 어떻게 보여줄지는 제안해줘. 
    - preview 음악을 사용
2. 최신곡 섹션
    - 자동으로 최신곡을 가져와서 표시
3. 인기 플레이리스트 섹션
    - 자동으로 인기 플레이리스트를 가져와서 표시
4. 사이트 플레이리스트 추천 알고리즘 소개 섹션
    - 사이트에서 제공하는 추천 알고리즘을 소개하는 페이지 링크를 제공
5. 최신 추천 플레이리스트 섹션
    - gms 최신 추천 플레이리스트를 5개정도 가져와서 표시
6. 멜론 핫 100 플레이리스트 섹션
    - 멜론 핫 100 중 10곡 표시 하고 플레이리스트 전체 페이지로 이동 링크
