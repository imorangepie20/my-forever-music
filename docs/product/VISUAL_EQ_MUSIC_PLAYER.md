# VISUAL EQ MUSIC PLAYER
## TIDAL 전용
    - 스트리밍 플랫폼으로 타이다을 선택 인증한 사용자만 사용 가능하다.
    - 다른 플랫폼 사용자는 해당 기능이 가려져야한다.
## Tracks 목록
    - 플레이리스트 재생인경우 플레이리스트에서 재생 중인 트랙 정보가 좌측에 표시되어야한다.
    - 단일 트랙 재생인 경우 현재 재생중인 트랙 정보가 표시되어야한다.
## 플레이리스트나 트랙관련 이미지와 텍스트가 표시되어야 하며 애니메이션 효과를 주어야한다.
    - 애니메이션은 애니메이션 풀에서 랜던하게 가져와 실행한다.
    - 관련 이미지와 텍스트는 관련 모델을 구현하여 사용한다.(LLM)
